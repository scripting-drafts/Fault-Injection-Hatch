FAULTLAB RESCUE USB (UEFI)

Boot from this USB via the firmware boot menu.
Choose "Auto-restore faultlab ..." to restore the host boot configuration.
The rescue initramfs is self-contained; the host kernel comes from /boot.
Secure Boot must be off for this unsigned loader.
Fallback: "Root shell (init=/bin/bash)".
This media can modify the installed system. Keep it physically secure.
